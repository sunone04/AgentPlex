## 二、配套技术（随核心选型确定）

| 维度 | 选型 | 说明 |
|---|---|---|
| ORM | **Drizzle** | TS 优先、SQL 透明、无独立引擎进程；审计场景需精细 SQL 控制 |
| UI 组件库 | **Ant Design 5** | 管理控制台与桌面端共享组件 |
| 实时通信 | **WebSocket**（NestJS Gateway） | 会话流、Agent 状态推送、审批通知 |
| 任务队列/定时调度 | **Redis + BullMQ** | 定时任务调度器（spec §3.5）、审批异步流 |
| LLM 模型网关 | **Vercel AI SDK**（OpenAI-compatible） | 统一接 OpenAI / Claude / DeepSeek / 通义千问 / Llama，流式输出原生支持 |
| 测试 | **Vitest** + Playwright（E2E） | 与 Vite/Turborepo 工具链一致 |
| 部署 | Docker Compose（MVP）→ K8s Helm（企业版） | 对齐 spec §3.4.2 部署交付策略 |

## 三、Monorepo 结构

```
agentplex/
├── apps/
│   ├── desktop/        # Electron 桌面端（执行引擎 + 会话 UI）
│   ├── server/         # NestJS 云端服务（API + 调度 + 连接器网关）
│   └── console/        # React Web 管理控制台
├── packages/
│   ├── core/           # Agent 核心循环、会话状态、工具协议（双端共享）
│   ├── sandbox/        # 沙箱抽象层（Docker / 受限进程双实现）
│   ├── tools/          # 原子工具集（Read/Write/Edit/Glob/Grep/Bash/WebSearch...）
│   ├── ui/             # 共享组件库（console 与 desktop 复用）
│   └── shared/         # 类型定义、协议、工具函数
├── docker/             # Dockerfile + compose + helm
└── docs/               # 规格书、技术选型、ADR
```
